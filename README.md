
# 🧍 Parsa WindowPet

**A lightweight desktop stickman pet for Windows.**  
**یک ادمک دسکتاپی سبک و بامزه برای ویندوز.**

---

## 🇬🇧 English

### About

**Parsa WindowPet** is a small desktop companion for Windows.  
It places a stickman character on the desktop that can move around and interact with the desktop.

### ✨ Features

- 🧍 Desktop stickman character
- 🚶 Walking animation
- 🧗 Movement and climbing
- 🖱️ Mouse interaction
- ⚡ Lightweight and low resource usage
- 🪟 Designed for the Windows desktop
- 🎨 Simple and clean design
- 💻 Built with Python and PySide6

### 📥 Download

Download the latest Windows version from the **Releases** section of this repository.

### 🖥️ System Requirements

- Windows 10 / Windows 11
- 64-bit Windows recommended
- The EXE release does not require Python to be installed

### 🛠️ Built With

- Python
- PySide6
